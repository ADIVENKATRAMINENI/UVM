<h1>🔹 RISC-V CPU Verification (UVM) - Project Overview</h1> <h2>📌 Project Summary</h2> <p> This project verifies a <strong>RISC-V CPU</strong> using <strong>SystemVerilog and UVM methodology</strong>. It includes complete stimulus generation, checking, scoreboard, coverage, and assertions. </p> <ul> <li>Instruction fetch, decode, ALU, memory, branch, and jump verification</li> <li>Assertions for control and memory signals</li> <li>Scoreboard compares DUT outputs vs expected reference model</li> <li>Monitor publishes instruction and memory transactions via analysis ports</li> <li>Functional coverage for instruction types, PC, registers, memory operations</li> <li>Directed and random tests for full verification</li> </ul> <h2>🎯 Features Verified</h2> <ul> <li>R-type instructions (ADD)</li> <li>I-type instructions (ADDI)</li> <li>Load/Store instructions (LW, SW)</li> <li>Branch instructions (BEQ)</li> <li>Jump instructions (JAL)</li> <li>Register file read/write correctness</li> <li>Memory data correctness</li> <li>PC and instruction alignment</li> </ul> <h2>🧩 UVM Components Included</h2> <ul> <li><strong>Sequence Item</strong> – instruction, PC, rs1, rs2, rd, op1, op2, ALU result, branch_taken</li> <li><strong>Driver</strong> – drives instructions and memory operations to DUT</li> <li><strong>Monitor</strong> – observes instruction fetch and memory transactions</li> <li><strong>Scoreboard</strong> – reference CPU model comparing expected vs DUT outputs</li> <li><strong>Coverage</strong> – instruction type, register, memory, and branch coverage</li> <li><strong>Agent</strong> – Driver + Monitor</li> <li><strong>Environment</strong> – Agent + Scoreboard + Coverage</li> <li><strong>Tests</strong> – directed and stress tests for each instruction type</li> </ul> <h2>📝 Testcases Implemented</h2> <ul> <li> riscv_reset_test — reset behavior and NOP instruction</li> <li> riscv_rtype_test — ADD instruction sequence</li> <li> riscv_itype_test — ADDI instruction sequence</li> <li> riscv_load_test — LW instruction sequence</li> <li> riscv_store_test — SW instruction sequence</li> <li> riscv_branch_test — BEQ instruction sequence</li> <li> riscv_jump_test — JAL instruction sequence</li> <li> riscv_stress_test — back-to-back instructions to test hazards</li> </ul> <h2>📊 Flow</h2> <p>The verification flow used here matches industry standards:</p> <ol> <li>Directed reset test</li> <li>Directed instruction type tests</li> <li>Load/Store and branch/jump tests</li> <li>Random instruction sequences for stress testing</li> <li>Functional coverage measurement</li> <li>Assertions + Scoreboard checking</li> <li>Regression and sign-off</li> </ol> <h2>🏁 Conclusion</h2> <p> This project demonstrates a clean, modular, and fully reusable RISC-V CPU UVM testbench. It verifies CPU behavior thoroughly using a combination of: </p> <p><strong> Assertions +  Scoreboard +  Coverage +  Random / Directed Tests</strong></p>
